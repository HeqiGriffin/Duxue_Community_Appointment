# 笃学书院微信小程序前端（Phase 3）

本目录直接对接后端 `0.3.0` 的 `/api` 接口，实现：

- 白名单账号登录与首次登录强制修改密码
- 首页账号/冻结状态、个人预约记录
- 自然语言用途预约（30 分钟粒度）
- 有效预约时段内签到并获取 i大工动态二维码
- 预约结束后只允许实时相机拍摄并上传离场照片
- 冻结账号线上申诉与历史处理结果

## 本地联调

1. 启动 `backend_fastapi`，默认监听 `http://127.0.0.1:8000`。
2. 使用微信开发者工具导入 `frontend_miniapp` 目录。
3. `project.config.json` 已关闭开发阶段 URL 校验；默认 API 地址是 `http://127.0.0.1:8000/api`。
4. 真机调试或上线时，将 `app.js` 的 `apiBaseUrl` 改为可从手机访问的 HTTPS 域名，并在微信公众平台配置 request/uploadFile 合法域名。
5. 动态二维码接口还要求后端正确配置 `IDUT_QR_URL` 和 `IDUT_COOKIE`。

## 时间约定

校园业务时间统一按 `Asia/Shanghai (UTC+8)` 处理。预约页直接向后端发送带 `+08:00` 的 ISO 8601 时间，避免用户手机处于其他时区时发生偏移。

当前后端 0.3.0 限制“单笔预约不跨自然日”，因此本前端时间选择也遵守该接口约束。若最终需要支持 `23:30–00:00` 的跨零点半小时预约，应先同步调整后端时间窗口规则后再开放该时段。
